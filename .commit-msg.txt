feat: fetch_url tool (web interaction) + ROADMAP Fase 3 complete

New fetch_url tool enables Mia to open a public URL and read its article
text on demand, closing the last Fase 3 capability gap. Combined with the
existing web_search, the assistant can now both find pages and read them:
- SSRF protection: blocks localhost, private IPs, loopback, link-local,
  AWS metadata, non-HTTP schemes, and hostnames without a dot (TLD check).
- Timeout (12s), size cap (120KB), bounded output (2000 chars to LLM).
- HTML text extraction: prefers og:description, <article>, <main>, then
  <body>; strips tags/scripts for clean article text. Non-HTML returned as-is.
- Risk: read (auto-executes, no confirmation).

Verified: 7/7 SSRF targets rejected (127.0.0.1, localhost, 10.x, 192.168.x,
169.254.x, file://, host without dot); live fetch of example.com returns clean
article text; 404 handled gracefully (conversational error). typecheck/lint/
vitest(9)/verify green.
