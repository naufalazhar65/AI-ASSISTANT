# USER.md

Notes: stable facts about the people I talk to, written automatically when
they share them (name, language, preferences, and so on). This is the single
source of truth for user facts.

The facts about the OWNER live in ONE place: `.data/users/<owner>/persona/USER.md`.
This template seeds that file on first use, so it must not assert facts that
drift — the trio agents (Mia, Agnes, Michelle) all read the same file, and a
stale copy here made two of them quote a different city. The seed stays
minimal; the lived facts accumulate in the owner's own file.
